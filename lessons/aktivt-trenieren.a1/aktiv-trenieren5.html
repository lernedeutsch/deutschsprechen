Teil 1 · Personalpronomen

Teil 2 · du oder Sie?

👆 Person wählen → 👀 Situation ansehen → 👆 du oder Sie wählen
Wybierz osobę → spójrz na sytuację → wybierz du albo Sie.
Wähle eine Person.

Teil 3 · Verben im Präsens

👀 Pronomen lesen → 👆 richtige Verbform wählen → 🔊 Satz hören
Przeczytaj zaimek → wybierz poprawną formę czasownika → posłuchaj zdania.

arbeiten

Teil 4 · Dialoge

🔊 Dialog anhören → 🎭 Rolle B sprechen → 👆 Antwort prüfen
Posłuchaj dialogu → mów jako osoba B → kliknij ukrytą odpowiedź, aby sprawdzić.

Sprechen · Antworte selbst

👆 Frage wählen → ✏️ Antwort schreiben → 🔊 deine Antwort hören
Wybierz pytanie → wpisz odpowiedź → posłuchaj swojej odpowiedzi.
