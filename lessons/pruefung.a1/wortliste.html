Wortliste-Check

Kontrola programu 1–30

Oficjalna Wortliste Goethe A1 zawiera około 650 haseł; Goethe podaje, że wszystkie powinny być rozumiane pasywnie, a około połowa powinna być dostępna aktywnie. Ta strona służy jako kontrola obszarów, które kurs musi pokrywać.

✓ Person & persönliche Daten — L1–6
✓ Wohnen — L7
✓ Umwelt / Wetter — L16
✓ Reisen / Verkehr — L15, L23–24
✓ Essen / Trinken — L8, L25
✓ Einkaufen / Kleidung — L9, L26
✓ Schule / Lernen — L27
✓ Arbeit / Beruf — L4
✓ Freizeit / Sport / Kultur — L12–14
✓ Gesundheit — L17
✓ Zahlen / Datum / Uhrzeit — L2–3, L10–11
✓ Farben — L26
✓ Prüfungswortschatz — L29–30 + Prüfungstraining

Obszary do świadomej powtórki

Oficjalny spis obejmuje również słownictwo usług publicznych (np. poczta, bank, policja), zakwaterowania/bagażu, telefonu oraz typowe słowa poleceń egzaminacyjnych. Te elementy są celowo ćwiczone w nowym Prüfungstraining i powinny być sprawdzane w powtórkach, nawet jeśli nie mają osobnej lekcji.

Ważne: to kontrola pokrycia programu; nie zastępuje oficjalnej listy Goethe słowo po słowie.
